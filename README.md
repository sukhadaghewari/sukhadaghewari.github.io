# sukhadaghewari.github.io

Edit a file on github.com (pencil icon), then **Commit changes**. The site updates in about a minute.
Each data file explains its format at the top.

| To add or change | Edit |
|---|---|
| An update | `_data/news.yml` (the newest 3 show on the home page) |
| A paper, tutorial or poster | `_data/publications.yml` |
| A role, degree or award | `_data/cv.yml` |
| Your CV | upload a new `assets/cv.pdf` (same name) |
| The About text | `index.html` |
| Name, tagline, topic tags, links | `_config.yml` |
| A blog post | a new file in `_posts/`, named `YYYY-MM-DD-title.md`, started from `_templates/new-post.md` (or `substack-post.md` for a Substack link) |

If a change breaks the site, the **Actions** tab shows a red ✗ with the error; the live site keeps the last working version.
